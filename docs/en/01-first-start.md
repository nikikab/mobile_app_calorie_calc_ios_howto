# 1. First start and language

What you see when you first open KaloCalc and how to change the language.

**Prerequisites:** None. The app is free and needs no account. It runs on an iPhone with iOS 17 or later.

## Steps

1. Open KaloCalc. The start screen is the **Diary** tab: today, the daily goal (calories and macros) and the four meals. The five tabs are at the bottom: **Diary**, **Progress**, **Goal**, **Settings** and **Help** (it opens this guide in the browser).

   ![First start and language – 1](../../media/01-first-start/en-01-diary.png)

2. To change the language open **Settings** and pick it from **Language**: English, Bulgarian, German, French or Spanish. The whole interface switches at once and the choice is remembered.

   ![First start and language – 2](../../media/01-first-start/en-02-settings.png)

## Result

On first run the app follows the iPhone language if it is one of the five, otherwise English.
