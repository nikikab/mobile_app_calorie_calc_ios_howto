# 1. Erster Start und Sprache

Was du beim ersten Öffnen von KaloCalc siehst und wie du die Sprache änderst.

**Voraussetzungen:** Keine. Die App ist kostenlos und braucht kein Konto. Sie läuft auf einem iPhone mit iOS 17 oder neuer.

## Schritte

1. Öffne KaloCalc. Der Startbildschirm ist der Tab **Tagebuch**: heute, das Tagesziel (Kalorien und Makros) und die vier Mahlzeiten. Die fünf Tabs liegen unten: **Tagebuch**, **Verlauf**, **Ziel**, **Einstellungen** und **Hilfe** (öffnet diese Anleitung im Browser).

   ![Erster Start und Sprache – 1](../../media/01-first-start/en-01-diary.png)

2. Zum Ändern der Sprache öffne **Einstellungen** und wähle sie unter **Sprache**: Englisch, Bulgarisch, Deutsch, Französisch oder Spanisch. Die ganze Oberfläche wechselt sofort und die Auswahl wird gemerkt.

   ![Erster Start und Sprache – 2](../../media/01-first-start/en-02-settings.png)

## Ergebnis

Beim ersten Start folgt die App der iPhone-Sprache, wenn sie eine der fünf ist, sonst Englisch.
