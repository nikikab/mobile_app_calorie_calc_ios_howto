# 4. Rechercher un aliment et code-barres

Trouvez un produit dans Open Food Facts par nom ou code-barres et ajoutez-le avec une portion.

**Prérequis:** Connexion internet.

## Étapes

1. Touchez **+** dans le **Journal**. Choisissez le repas et saisissez le nom dans **Nom du produit**, puis touchez Rechercher sur le clavier. Vos favoris sont listés sous le champ ; touchez-en un pour le rajouter.

   ![Rechercher un aliment et code-barres – 1](../../media/04-search-and-barcode/en-01-search-home.png)

2. Choisissez un produit dans les résultats. Chaque ligne indique les calories pour 100 g.

3. Saisissez les grammes. Les calories et les macros sont calculées. Touchez **Ajouter**.

4. Pour un code-barres, touchez **Scanner un code-barres** et dirigez l'appareil photo vers le code sur l'emballage. La première fois, iOS demande l'autorisation de l'appareil photo ; si vous avez refusé, autorisez-la dans l'app Réglages de l'iPhone, sous KaloCalc → Appareil photo.

## Résultat

Si une recherche donne peu ou rien et que vous avez une clé Gemini, l'application la traduit en français, cherche de nouveau et renvoie les résultats dans votre langue. Si un code-barres n'est pas dans la base, vous recevez un message et pouvez ajouter l'aliment manuellement.
